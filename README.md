# Flanker-task
A computerized Flanker task developed for an independent cognitive psychology research project on attention and cognitive control.

# Project overview
The Flanker task measures selective attention and inhibitory control by comparing responses to congruent and incongruent stimuli. This version incorporates color-coded conditions to support the experimental manipulation and comparison of attentional performance across conditions.

# Respository contents
-'Flanker PSYC4007.psyexp'- editable Psychopy Builder experiment
-'flanker_task.py'- compiled Python version of the experiment
-'conditions.xlsx'- main experimental conditions
-'blocks_A.xlsx' and 'blocks_B.xlsx'- block-specific conditions, used to eliminate order effect
